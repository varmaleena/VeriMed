# Phase 1 CKS reference-client verification

This slice implements public-reference retrieval, not a deployed CKS service or clinical safety engine.
UI work is deferred. No new AWS resources were created by these checks.

Run from the repository root in PowerShell:

    .venv/Scripts/python.exe -m pytest services/cks/tests -q
    ./scripts/Test-CksReferences.ps1

The live command accepts only a de-identified drug name/strength through -Drug.
Never supply patient notes or identifiers. Input validation is not a PHI scrubber.
Each run replaces docs/cks-verification.json with public-reference metadata and response hashes;
the report contains no label prose or clinical records.

On November 19 the metformin query produced one normalized candidate; exact lookup of its
preferred name produced two concepts. No RxCUI was selected automatically.
Candidate transport probes fetched 32 and 34 class memberships and three labels each.
Both class results require review for unspecified relationships; label totals were 95 and 79,
so the three-label responses are explicitly partial. These checks passed transport/parsing,
not clinical correctness or a complete safety assessment.

The library uses bounded asynchronous HTTP, timeouts, retries, strict response schemas,
source provenance, OTel fetch spans, and structured outcome logs/metrics without query text.
Unit tests use doubles only inside tests and cover malformed providers, ambiguity, missing
coverage, timeouts, redirects, query validation, and log redaction.
Per-client spacing is not a distributed production quota limiter.

The JSON contract is packages/api-client/cks.schema.json, generated by services/cks/export_schema.py.
CI regenerates it and checks for drift. No network-facing endpoint is exposed by this slice;
authentication, authorization and cross-account negative tests must accompany service deployment.

The enterprise target is a separate PHI-free hub account with PrivateLink access from cells.
Only the standalone dev-cell profile is configured. See BLOCKERS.md and ADR 014.
Hub hosting, PrivateLink, Valkey caching, reference mirroring and Phase 1 deployed acceptance
are pending. Public API smoke probes create no AWS charges; no new AWS spend was incurred here.

Validation: 73 Python unit tests passed (21 CKS, 52 API), Ruff check/format passed,
and strict mypy passed across 31 API/CKS source files. Schema generation and formatting passed.
Three existing framework deprecation warnings remain. Hosted CI is unverified because no Git remote is configured.
